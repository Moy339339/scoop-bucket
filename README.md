# Scoop bucket

[Scoop](https://scoop.sh) manifests for apps by MoyGoldenAge.

```powershell
scoop bucket add moygoldenage https://github.com/Moy339339/scoop-bucket
scoop install moygoldenage/sniptoss
```

| App | Description |
|---|---|
| [SnipToss](https://github.com/Moy339339/SnipToss) | Annotate AI-generated images and videos, then hand the notes back to your coding agent. Windows 11, x64. |

SnipToss runs as a portable app here: its settings, logs and screenshots are kept in Scoop's `persist` folder, so `scoop update` keeps them.
